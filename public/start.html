Freddie’s guide to working on the website

You’re going to work on the new GFP website with Claude Code. It’s Claude, but it can open, change and save the website’s files on your Mac for you.

You tell it what you want in normal words, like “make the episode titles bigger”, and it does the fiddly bits.

What you need

  • Your Mac
  • Your Claude subscription (the one you already pay for)
  • About 30 minutes, once. After that it’s quick.

1 Open Terminal

Terminal is an app that’s already on your Mac. Instead of clicking things, you type instructions. It looks a bit hacker-ish, but you’ll only type a few words in it.

  1. Press ⌘ Cmd + Space. A search bar appears.
  2. Type Terminal and press Return.
  3. A window with some text and a blinking cursor opens. That’s it.

How to paste things in: click a yellow Copy button on this page, click in the Terminal window, press ⌘ Cmd + V, then press Return.

2 Install Claude Code

Copy this, paste it into Terminal, and press Return:

curl -fsSL https://claude.ai/install.sh | bash

Lots of text will scroll past. Wait until it stops and the blinking cursor is back (usually under a minute).

Now quit Terminal completely (⌘ Cmd + Q) and open it again, the same way as in step 1. This lets your Mac notice the new app.

Check it worked

Paste this and press Return:

claude --version

If you see a version number (something like 2.1.0 (Claude Code)), you’re done with this step. 🎉

If it says “command not found”: paste this, press Return, then quit and reopen Terminal and try again:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

3 Make a folder for the website

The website will live in its own folder inside your Documents folder. Paste this and press Return:

mkdir -p ~/Documents/GFP-Website

Nothing visible happens, and that’s fine. If you open Finder and go to Documents, there’s now an empty folder called GFP-Website. Don’t put anything in it. Claude will fill it in a minute.

4 Go into the folder and start Claude

First, tell Terminal to “go into” that folder (cd means “change directory”, which is nerd for “open folder”):

cd ~/Documents/GFP-Website

Then start Claude Code:

claude

The first time only, it asks a few setup questions

  1. Pick a colour theme: any is fine. Use the arrow keys, then press Return.
  2. How do you want to log in? Choose Claude account with subscription.
  3. Your web browser opens. Log in to Claude if asked, then click Authorize. Go back to Terminal.
  4. If it asks Do you trust the files in this folder?, choose Yes.

You’ll then see a box where you can type to Claude. You’re in! 🙌

5 Paste in this message, and Claude does the rest

Copy the whole message below, paste it into Claude, and press Return. Claude will walk you through everything else, one step at a time: making a GitHub account (where the website’s files are kept), installing a couple of tools, downloading the website, and showing it to you.

Hi Claude! I'm Freddie, co-host of The Generic Foiling Podcast. My mate Ben has built our new website and I want to work on it with you. I'm NOT technical at all, so please: - go one step at a time, and wait for me to say I've done each thing before moving on - explain everything in plain, simple English with no jargon - tell me exactly what to click or type whenever I need to do something myself The folder you're running in right now (~/Documents/GFP-Website) is where the website should live. Here's what I need: 1. GITHUB ACCOUNT. The website's files are kept on GitHub, in Ben's private project "benfgillespie/freddie". I don't have a GitHub account yet. Walk me through signing up at https://github.com/signup on the free plan, confirming my email, and turning on two-factor login (a passkey using Touch ID is probably easiest, and remind me to save the recovery codes somewhere safe). Then tell me to message Ben my GitHub username so he can invite me to the project, and explain how to accept the invite when the email arrives. Wait until I tell you I've accepted it. 2. TOOLS. Check whether my Mac has Git, the GitHub command-line tool (gh) and Node.js, and install whatever is missing in the simplest way you can. If my Mac pops up a box asking to install "command line developer tools", tell me to click Install and wait for it to finish. 3. CONNECT TO GITHUB. Help me log in with "gh auth login" (GitHub.com, HTTPS, log in with a web browser), and set up Git with my name and email. 4. GET THE WEBSITE. Download (clone) benfgillespie/freddie into this current folder. Then read CLAUDE.md in the project so you know how it all works. 5. SHOW ME IT. Run "npm install", start the site with "npm run dev", and open http://localhost:3000 in my browser so I can see it. 6. QUICK LESSON. Finish with a short, simple cheat sheet of what to say to you to: make a change, see it, save my work to GitHub, get Ben's latest changes, and undo something. If anything goes wrong, explain what happened in simple words and fix it. If you can't fix it, tell me exactly what to send Ben.

Claude will ask permission before doing things, like Do you want to run this command? Read what it says, then choose Yes (press Return).

If it asks for your Mac password, type it and press Return. Nothing appears on screen while you type. That’s normal, it’s a security thing.

★ Every time after that

  1. Open Terminal (⌘ Cmd + Space, type Terminal, Return).
  2. Go into the website folder:
    cd ~/Documents/GFP-Website
  3. Start Claude:
    claude
  4. Ask for what you want, in normal words.

Things you can say

  • “Start the website and open it in my browser”
  • “Change the homepage headline to …”
  • “Use the photo called liam-new.jpg in my Downloads folder for Liam’s picture”
  • “The shop looks squashed on my phone. Can you fix it?”
  • “Undo that last change”
  • “Save my work to GitHub”: do this at the end of every session. It backs everything up and lets Ben see it.
  • “Get Ben’s latest changes”: do this at the start if Ben’s been tinkering.

Handy to know

  • Seeing your changes: refresh the browser tab showing localhost:3000. Only you can see that version. It’s running on your Mac.
  • Want it online to show Liam or check on your phone? Save to GitHub, then message Ben and he’ll put it up.
  • Stuck? Tell Claude exactly what you see. You can drag a screenshot straight into the Terminal window.
  • Nothing can really break. Every saved version is kept, so you can always go back.
  • To leave Claude: type /exit and press Return, or just close the window.
